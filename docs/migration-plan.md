### 固定试用入口

复用 Tailscale 提供域名与 HTTPS 证书，在它后面接本机受管网关：同一来源同时提供冻结前端、现有 `/v1` API、协作与运行事件流、上传、签名文件和头像。浏览器不再依赖另一个 HTTP API 地址；反向代理必须保留流式传输、查询参数及现有授权语义。复用已有网关实现，先核对当前路径拼接与 SSE 行为，再确定配置，不另写一套服务框架。

- [Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)：统一向已有 Tailscale 的测试设备提供网络内 HTTPS，沿现有网络访问权限使用；链接不开放到公网。
- 固定入口的后台配置、服务自启动、资源限额、版本指向、健康检查与回滚步骤一并交付；不再依赖临时隧道。测试流量只经过试用网关，不额外开放数据库或插件／沙箱服务。
- Safari 从地址栏或新标签直接打开 HTTPS。记录实际加载的 Wasm／渲染器、协议和原生时间线；不把 `isSecureContext` 当作 JIT 证明。既有约80%的回调耗时改善来自 iOS27 模拟器的同包对照，实体 iPhone 仍单独复核。
