菜单组成、外观最终状态、TTS 输入和就绪契约的变化是测量修正，不能全部归功于产品像素改进。运行用例中的真实开始／自动保存时间仍可能不同，原图保留，不遮掉文字或改 SSE 来消分。

相同透明色、底色及输入可在 CSS 与 Skia 合成后差一个通道单位，最小复现三次稳定。这证明存在绘制差异，不证明每个残余都由它造成，也不豁免严格评分。

代码面板还确认了独立差异：原版 Monaco 的软换行续行保留缩进，本项目 EditableText 的续行从左边界开始。后续修复须复用固定版换行规则，同时保持逻辑文本、光标、选区和输入法映射；不能往用户代码插入空格或逐行偏移。字体大小／居中不应为此再次调整。
