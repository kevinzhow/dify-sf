## 使用与限制

以后新增共享导出、页面类或节点面板键须更新 `ui_coverage.json`，否则正常控件回归入口失败；有清单不等于已成功抓图。完整步骤见 `UI_TESTING.md`：固定原版导出、构建真实宿主、私有隔离会话、抓图、严格汇总、原版 diff/site，再审阅原图和 Matrix。私有会话、cookie、header 和环境文件不进入仓库或报告。

本轮用了隔离账号、应用和服务；页面数据替身只证明界面状态，不证明服务端集成。运行相关场景只允许新建应用中的 Start／Variable Aggregator／End 或固定 Answer，并已通过两端真实 HTTP 成功检查；未调用模型、代码沙箱、HTTP 节点或工具，没有费用。未登录实际试用用户、写入其测试数据、变更密钥／数据库／服务配置或升级其前端。原试用仍为 c072d49，四项匿名在线资源哈希一致。

没有实体 Android、TalkBack、Safari 或所有页面中英文状态的验收。整体迁移与上述真实视觉差异仍未完成；本轮交付的是可复现的测试标准、完整声明矩阵的原始结果和待修清单。
