## 数据与权限

新索引服务关闭匿名访问，使用独立私有 key 和持久卷，不发布主机端口，限制 640 MiB／1 CPU。
原 PostgreSQL 卷、上传卷、账号、已加密供应商／工具凭据、应用密钥及文件签名密钥保留。
旧版标注只有启用标志，没有向量索引，迁移后标为 `needs_rebuild`，等待用户主动启用；
升级不会自动使用用户的现有模型凭据建索引。

试用更新前保留数据库与上传备份、原容器和回退说明；对实际试用只做匿名健康、资源哈希、Wasm 和同源检查。
不把真实账号或备份当成测试夹具。安装／升级验证另外克隆一次性旧测试库，使用受控模型与工具凭据。
邮件能力继续关闭，插件市场、计费、知识库和完整原版生成器不属于本次完成范围。
